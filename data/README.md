# Data directory

This directory holds all local data for the lab. Nothing in it is committed to git except this README and the `.gitkeep` placeholders. Data is treated as generated or externally sourced material that each machine produces or downloads for itself, which keeps the repo small and avoids committing files that can drift out of sync with the code that created them.

## Layout

- `raw/` holds original, immutable datasets exactly as obtained. Files here are never edited in place. In Phase 0 this directory is empty because the smoke lifecycle uses synthetic data only.

- `interim/` holds generated intermediate data produced during transformation steps. Anything here can be deleted and regenerated. Empty in Phase 0.

- `processed/` holds final, deterministic outputs ready for training and evaluation. In Phase 0, `make train` writes the smoke train/test splits and split manifest to `processed/smoke/`. The test split is written once by training and is never regenerated by evaluation.

## Rules

Raw data is not committed by default. If a dataset ever needs to be shared, it belongs in external storage, not in this repo. Generated data in `interim/` and `processed/` is always reproducible from code and a fixed seed, so it is ignored by git as well.
