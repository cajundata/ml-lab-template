- **The local pipeline is deterministic, byte-for-byte.** `SMOKE_SEED = 20260706`, 240 rows, a fixed linear score, a threshold at zero, and a **no-shuffle** 180/60 split. `split_manifest.json` carries SHA-256 checksums of both CSVs, and those row counts are folded into the MLflow params — so every run records exactly which bytes it trained on. Do not introduce a shuffle, a time-dependent seed, or an unseeded RNG.
- **Evaluation loads the model and the test split from disk**, never from memory. That is what makes a broken `save()`/`load()` round-trip impossible to pass silently.
- **Schema validation is enforced at predict time**, not just at load: column list must match *exactly* (order included) and every feature column must be numeric, else `SchemaValidationError`. A model that silently accepts reordered columns silently returns garbage.
- **Training and evaluation must land in the same MLflow run.** Two runs would break the trace from a saved model back to its metrics.
- **The GPU benchmark always writes a partial bundle**, even when probes fail. A probe that raises has its traceback written into its own artifact and the remaining probes still run. Never let a failing probe abort the bundle — the bundle is the only evidence that survives the droplet.
